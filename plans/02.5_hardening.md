## Numbered Steps

### 1. Fix thread-unsafe global DB connection — `db/init.py`

The current code opens `_CONN` at module-import time and reuses it for all threads. FastAPI runs concurrently and SQLite will raise `ProgrammingError` under load. Replace with a `threading.local()` per-thread connection:

```python
import sqlite3
import threading
from pathlib import Path

DATA_DIR = Path(__file__).resolve().parent.parent / "data"
DB_PATH = DATA_DIR / "sigdriftr.db"
DATA_DIR.mkdir(parents=True, exist_ok=True)

_local = threading.local()


def get_conn() -> sqlite3.Connection:
    """Return a per-thread SQLite connection, creating it on first use."""
    if not hasattr(_local, "conn"):
        conn = sqlite3.connect(str(DB_PATH), check_same_thread=False)
        conn.execute("PRAGMA journal_mode=WAL")  # allows concurrent reads
        conn.execute(
            """
            CREATE TABLE IF NOT EXISTS articles (
                id           TEXT PRIMARY KEY,
                outlet       TEXT NOT NULL,
                title        TEXT NOT NULL,
                summary      TEXT,
                url          TEXT UNIQUE NOT NULL,
                topic        TEXT,
                published_at TEXT,
                fetched_at   TEXT NOT NULL
            );
            """
        )
        conn.execute(
            """
            CREATE TABLE IF NOT EXISTS signals (
                article_id         TEXT PRIMARY KEY,
                concern_level      REAL,
                purchase_intent    REAL,
                avoidance_signals  REAL,
                dominant_frame     TEXT,
                seg_young_urban    REAL,
                seg_family         REAL,
                seg_senior         REAL,
                seg_b2b            REAL,
                raw_json           TEXT,
                extracted_at       TEXT NOT NULL,
                FOREIGN KEY (article_id) REFERENCES articles(id)
            );
            """
        )
        conn.commit()
        _local.conn = conn
    return _local.conn
```

Remove the module-level `_CONN = sqlite3.connect(...)` call and all module-level `_CONN.execute(...)` calls entirely — everything moves inside `get_conn()`.

### 3. Add semantic topic filtering to the crawler — `ingestion/crawler.py`

Czech is a highly inflected language — keyword substring matching is lossy and error-prone (e.g. searching "auto" matches "automaticky"). Replace the naive `if topic_lower not in combined_text` check with a two-pass filter:
- **Pass 1 (fast):** Keep the existing keyword check as a cheap pre-filter.
- **Pass 2 (semantic):** Use `sentence-transformers` with `paraphrase-multilingual-MiniLM-L12-v2` to compute cosine similarity between the topic query embedding and the article embedding. Only keep articles above a threshold (0.25 works well empirically).

Load the embedding model once at module level (lazy singleton) to avoid reloading per article.

```python
import hashlib
from datetime import datetime, timezone
from functools import lru_cache

import feedparser

from config.feeds import FEEDS
from db.init import get_conn

SEMENTIC_THRESHOLD = 0.25  # cosine similarity minimum to accept article


@lru_cache(maxsize=1)
def _get_embedder():
    """Lazy-load the multilingual sentence embedder once."""
    try:
        from sentence_transformers import SentenceTransformer, util as st_util
        model = SentenceTransformer("paraphrase-multilingual-MiniLM-L12-v2")
        return model, st_util
    except Exception:
        return None, None


def _is_relevant(topic: str, title: str, summary: str) -> bool:
    """Two-pass relevance check: keyword pre-filter + semantic similarity."""
    combined = f"{title} {summary}".lower()
    topic_lower = topic.lower()

    # Pass 1: fast keyword check (also handles empty topic = accept all)
    if not topic_lower:
        return True
    keyword_hit = topic_lower in combined

    # Pass 2: semantic check (skip if keyword already hit for speed)
    if keyword_hit:
        return True

    model, st_util = _get_embedder()
    if model is None:
        return False  # embedder unavailable, rely only on keyword

    topic_emb = model.encode(topic, convert_to_tensor=True)
    article_emb = model.encode(combined[:512], convert_to_tensor=True)
    score = float(st_util.cos_sim(topic_emb, article_emb)[0][0])
    return score >= SEMANTIC_THRESHOLD


def crawl(topic: str) -> int:
    conn = get_conn()
    inserted = 0

    for feed in FEEDS:
        parsed = feedparser.parse(feed["rss_url"])

        for entry in parsed.entries:
            title = entry.get("title", "")
            summary = entry.get("summary", "")

            if not _is_relevant(topic, title, summary):
                continue

            url = entry.get("link", "")
            if not url:
                continue

            article_id = hashlib.sha256(url.encode()).hexdigest()
            cursor = conn.execute(
                "INSERT OR IGNORE INTO articles VALUES (?, ?, ?, ?, ?, ?, ?, ?)",
                (
                    article_id,
                    feed["outlet"],
                    title,
                    summary,
                    url,
                    topic,
                    entry.get("published", ""),
                    datetime.now(timezone.utc).isoformat(),
                ),
            )
            inserted += cursor.rowcount

        conn.commit()

    return inserted
```

### 4. Rewrite `extraction/llm_client.py` — retry + CoT + affinity prior + segment softmax

This is the most substantive change. Four improvements in one file:

**4a. Retry with exponential backoff** using `tenacity` — Ollama can be slow to start or occasionally time out. Never let a transient failure kill the whole batch.

**4b. Chain-of-Thought (CoT) prompt** — ask the model to reason first, then emit JSON. Dramatically improves accuracy on nuanced behavioral signals (Wei et al., 2022).

**4c. Affinity prior from feed tag** — if an article comes from a feed tagged `senior` (e.g. Blesk), start `seg_senior` at 0.6 instead of 0.25 before the LLM run. This is a free signal.

**4d. Segment softmax normalization** — after LLM extraction, normalize `seg_*` scores so they sum to 1.0 (they represent audience allocation, not independent probabilities).

```python
import json
import math
import urllib.error
import urllib.request

from tenacity import retry, stop_after_attempt, wait_exponential, retry_if_exception_type


OLLAMA_URL = "http://localhost:11434/api/generate"
OLLAMA_MODEL = "qwen2.5:7b-instruct"
OLLAMA_TIMEOUT_SECONDS = 120
VALID_FRAMES = {"fear", "opportunity", "conflict", "neutral"}

# Affinity priors: feed affinity_tag -> which seg_ to boost
AFFINITY_PRIORS = {
    "mainstream": {"seg_young_urban": 0.30, "seg_family": 0.30, "seg_senior": 0.25, "seg_b2b": 0.15},
    "b2b":        {"seg_young_urban": 0.15, "seg_family": 0.10, "seg_senior": 0.10, "seg_b2b": 0.65},
    "senior":     {"seg_young_urban": 0.10, "seg_family": 0.20, "seg_senior": 0.60, "seg_b2b": 0.10},
}

DEFAULT_SIGNALS = {
    "concern_level": 0.5,
    "purchase_intent": 0.0,
    "avoidance_signals": 0.0,
    "dominant_frame": "neutral",
    "seg_young_urban": 0.25,
    "seg_family": 0.25,
    "seg_senior": 0.25,
    "seg_b2b": 0.25,
}

PROMPT_TEMPLATE = """
You are a behavioral analyst specializing in Czech media. Analyze the article below.

Article title: {title}
Article summary: {summary}

Step 1 — Reason briefly (2-3 sentences): What emotions, consumer behaviors, or audience concerns does this article likely trigger?

Step 2 — Output ONLY this JSON block (nothing after it):
{{
  "concern_level": 0.0,
  "purchase_intent": 0.0,
  "avoidance_signals": 0.0,
  "dominant_frame": "<one of: fear|opportunity|conflict|neutral>",
  "seg_young_urban": 0.0,
  "seg_family": 0.0,
  "seg_senior": 0.0,
  "seg_b2b": 0.0
}}

Rules:
- All numeric fields are floats between 0.0 and 1.0.
- seg_* fields represent the relative relevance to each audience segment and should sum to approximately 1.0.
- dominant_frame must be exactly one of: fear, opportunity, conflict, neutral.
""".strip()


def _softmax_segments(signals: dict) -> dict:
    """Normalize seg_* fields so they sum to 1.0 using softmax."""
    seg_keys = ["seg_young_urban", "seg_family", "seg_senior", "seg_b2b"]
    raw = [signals.get(k, 0.25) for k in seg_keys]
    # softmax
    exps = [math.exp(v * 5) for v in raw]  # scale by 5 to sharpen distribution
    total = sum(exps)
    normed = [e / total for e in exps]
    for k, v in zip(seg_keys, normed):
        signals[k] = round(v, 4)
    return signals


def _apply_affinity_prior(signals: dict, affinity_tag: str) -> dict:
    """Blend LLM segment scores with the feed's affinity prior (70% LLM, 30% prior)."""
    prior = AFFINITY_PRIORS.get(affinity_tag)
    if prior is None:
        return signals
    for key in ["seg_young_urban", "seg_family", "seg_senior", "seg_b2b"]:
        signals[key] = round(0.7 * signals.get(key, 0.25) + 0.3 * prior[key], 4)
    return signals


def _clamp_score(value: object, default: float) -> float:
    try:
        return max(0.0, min(1.0, float(value)))
    except (TypeError, ValueError):
        return default


def _normalize_signals(result: dict | None) -> dict:
    normalized = dict(DEFAULT_SIGNALS)
    if isinstance(result, dict):
        for key, default in DEFAULT_SIGNALS.items():
            if key == "dominant_frame":
                frame = str(result.get(key, default)).strip().lower()
                normalized[key] = frame if frame in VALID_FRAMES else default
            else:
                normalized[key] = _clamp_score(result.get(key), default)
    return normalized


@retry(
    retry=retry_if_exception_type((urllib.error.URLError, TimeoutError, OSError)),
    stop=stop_after_attempt(3),
    wait=wait_exponential(multiplier=1, min=2, max=10),
    reraise=False,
)
def _ollama_request(payload: bytes) -> dict | None:
    """Single Ollama HTTP call — retried up to 3 times on network errors."""
    request = urllib.request.Request(
        OLLAMA_URL,
        data=payload,
        headers={"Content-Type": "application/json"},
        method="POST",
    )
    with urllib.request.urlopen(request, timeout=OLLAMA_TIMEOUT_SECONDS) as response:
        raw = json.loads(response.read().decode("utf-8")).get("response", "")
    # Extract the JSON block from CoT response
    start = raw.rfind("{")
    end = raw.rfind("}") + 1
    if start == -1 or end == 0:
        return None
    return json.loads(raw[start:end])


def _try_ollama(title: str, summary: str) -> dict | None:
    prompt = PROMPT_TEMPLATE.format(title=title, summary=summary)
    payload = json.dumps(
        {"model": OLLAMA_MODEL, "prompt": prompt, "stream": False, "format": "json"}
    ).encode("utf-8")
    try:
        return _ollama_request(payload)
    except Exception:
        return None


def _hf_fallback(title: str, summary: str) -> dict:
    """
    Minimal HuggingFace fallback using zero-shot classification to determine
    dominant_frame and derive concern_level. Returns DEFAULT_SIGNALS on any failure.
    """
    try:
        from transformers import pipeline
        classifier = pipeline(
            "zero-shot-classification",
            model="typeform/distilbert-base-uncased-mnli",
        )
        text = f"{title}. {summary}"[:512]
        result = classifier(text, candidate_labels=list(VALID_FRAMES))
        dominant_frame = result["labels"][0]
        scores = dict(zip(result["labels"], result["scores"]))
        concern = min(scores.get("fear", 0.0) + scores.get("conflict", 0.0), 1.0)
        return {**DEFAULT_SIGNALS, "dominant_frame": dominant_frame, "concern_level": round(concern, 4)}
    except Exception:
        return dict(DEFAULT_SIGNALS)


def extract_signals(title: str, summary: str, affinity_tag: str = "mainstream") -> dict:
    """
    Main entry point. Returns a normalized signal dict.
    Pipeline: Ollama (with retry) -> HuggingFace fallback -> DEFAULT_SIGNALS.
    Applies affinity prior and softmax segment normalization.
    """
    result = _try_ollama(title, summary)
    if result is None:
        result = _hf_fallback(title, summary)

    signals = _normalize_signals(result)
    signals = _softmax_segments(signals)
    signals = _apply_affinity_prior(signals, affinity_tag)
    return signals
```

### 5. Update `extraction/extractor.py` — pass affinity_tag

The extractor must now fetch the `outlet` from the articles table, look up the corresponding `affinity_tag` from `config/feeds.py`, and pass it to `extract_signals`.

```python
import json
from datetime import datetime, timezone

from config.feeds import FEEDS
from db.init import get_conn
from extraction.llm_client import extract_signals

# Build outlet -> affinity_tag lookup from config
_OUTLET_AFFINITY: dict[str, str] = {f["outlet"]: f["affinity_tag"] for f in FEEDS}


def run_extraction(topic: str) -> int:
    conn = get_conn()
    rows = conn.execute(
        """
        SELECT a.id, a.title, a.summary, a.outlet
        FROM articles a
        LEFT JOIN signals s ON a.id = s.article_id
        WHERE s.article_id IS NULL
          AND (a.topic = ? OR ? = '')
        """,
        (topic, topic),
    ).fetchall()

    processed = 0
    extracted_at = datetime.now(timezone.utc).isoformat()

    for article_id, title, summary, outlet in rows:
        affinity_tag = _OUTLET_AFFINITY.get(outlet, "mainstream")
        signals = extract_signals(title or "", summary or "", affinity_tag=affinity_tag)
        conn.execute(
            """
            INSERT OR IGNORE INTO signals
            (article_id, concern_level, purchase_intent, avoidance_signals,
             dominant_frame, seg_young_urban, seg_family, seg_senior, seg_b2b,
             raw_json, extracted_at)
            VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?)
            """,
            (
                article_id,
                signals["concern_level"],
                signals["purchase_intent"],
                signals["avoidance_signals"],
                signals["dominant_frame"],
                signals["seg_young_urban"],
                signals["seg_family"],
                signals["seg_senior"],
                signals["seg_b2b"],
                json.dumps(signals),
                extracted_at,
            ),
        )
        processed += 1

    conn.commit()
    return processed
```

## Notes for the coding agent

- Do NOT change the `signals` table schema — stage 3 reads it as-is.
- The `_ollama_request` function uses `tenacity` with `reraise=False` — on final failure it returns `None` (handled by `_hf_fallback`). Do not change this behavior.
- The CoT prompt ends with `rfind("{")` + `rfind("}")` to extract the last JSON block from the reasoning+JSON response. This is intentional — the model writes reasoning first, JSON last.
- `sentence-transformers` downloads the model on first use (~90 MB). This is fine in a hackathon context. The `@lru_cache(maxsize=1)` ensures it is loaded once per process.
- Softmax uses a scaling factor of 5 to prevent a flat distribution when all LLM scores are near 0.25. This is a deliberate choice to make the segment distribution more discriminative.
- If `sentence-transformers` is unavailable (import error), `_get_embedder()` returns `(None, None)` and the crawler falls back to keyword-only filtering. Never crash on import failure.
